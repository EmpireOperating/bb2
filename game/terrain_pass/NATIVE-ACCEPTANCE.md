# Parent native acceptance checklist

This is a planned acceptance protocol, NOT a report of execution.

Run the frozen source through canonical AO/default Omabox in private writable copy/state with runtime mounted read-only. No user checkpoint or active desktop access. Inspect pinned launcher activation before invocation. Keep all failed trials, source manifests, exact engine birth/exit and canonical cleanup receipts.

## Both maps

1. Launch default successor scene in new `ashen-company-terrain-rules` state. Observe valid saved camp; bind window to engine PID/starttime/argv before input.
2. Inspect full outfit camp preview. Select each authored map through ordinary camp UI. Check map IDs/title and no changes to company, item IDs/conditions, time or encounter counter. Map selection does not deploy; no equip/deploy behind a chooser modal.
3. Deploy Ruined Crossing. Verify real individual initiative, initial active origin, exact chosen map, expected real equipped figure. Capture default overview and closer readable bridge/ruin/bank view. Screenshots must show painted gameplay, not splash.
4. Use actual active bro clicks to move along a highlighted paid route, ideally a slope; compare observed AP/FAT deltas to observer/domain quote. Click enemy and execute an accepted real weapon action (miss allowed); end activations until real enemy action. No test dispatcher or state injection.
5. Inspect exact shared preview. Camera zoom/pan, opaque helmet/boot selection and transparent margins; actual terrain fading/restore when an occluder hides a unit. Inspect screenshot pixels for grass/road readability, actual heights, cliff approaches and no new gear color/alpha regressions.
6. Retreat via confirm/cancel, then confirmed ordinary withdrawal, return to camp. Check actual wear/results preserved and checkpoint saved. Keep headless victory/casualty evidence separate from native retreat.
7. Choose Woodland Road on the same ongoing company, proving no fresh grants/heals. Deploy, verify no crossing river/bridge/keep, correct raised flank/wooded-edge geometry and road. Repeat real movement/attack/enemy-response and capture terrain detail/overview. Terrain masks must agree with logical blocker rules; no trees drawn in mechanically clear standing centers.
8. Return to camp, close exact engine and await wrapper final/source receipt. Cold relaunch in same private HOME, compare exact persisted company/inventory/results. Map preference may intentionally reset to crossing; document separately, never mislabel it as persisted.
9. Exit and verify exact window/engine retirement and canonical desktop cleanup. Software rendering qualifies this tested route, not target-GPU FPS or other platforms.

## Rules boundary

Headless source-bound tests establish numerical terrain rules and command atomicity. Native presentation fading is NOT combat visibility. Do not call old hard-blocking LOS, native height-sensitive visibility, or projectile-cover/scatter vanilla-complete unless the source follow-up and actual implementation/tests explicitly establish them.

## Visual decision

Look for quieter large grass/earth groups, visible road and damp banks, more coherent ruined footprint, broad natural elevated ground, and a genuinely different woodland composition. Increased mesh count or test totals are not visual acceptance. Keep accepted full-body sprites/menus unchanged. If the current candidate is not visibly stronger, make a small terrain-only correction and bind final bytes to native proof; do not reopen equipment art.
